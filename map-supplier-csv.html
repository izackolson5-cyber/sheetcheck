How to map a supplier spreadsheet to Shopify's product CSV format

Supplier spreadsheets often don't match Shopify's import format. Before a supplier file can become products in your store, every column has to be mapped to a field Shopify understands, and a few judgement calls have to be made. This is how to do that mapping without creating problems you will be fixing for days afterwards.

Start from a real export, not a blank sheet

The fastest way to get the exact column names right is to export a product you already sell from your own store (Products → Export). That file shows the exact headers your store uses today. Shopify also publishes a sample CSV and a column reference in its help centre, and it keeps older column names working - an export from your own store is still the safest reference because it reflects your setup.

The columns that matter

You do not need every column. These are the ones that decide whether an import goes well:

Shopify columnWhat to put in it from the supplier file
URL handle (older files: Handle)One per product, repeated on every variant row. Lowercase letters, numbers and dashes, no spaces. If the supplier has a product code, it can work as the handle.
TitleThe product name, on the first row of each product only.
VendorThe supplier or brand name.
Option1 Name / Option1 Value (and Option2/3)Size, Colour and so on. Every variant of a product needs its own row with the same handle and its own option values. If a product has no variants, Shopify uses Default Title here.
SKUThe supplier's SKU is usually the right value - it keeps restocking and reordering matchable later. Each SKU should appear once.
PriceYour selling price, as a plain number like 19.99 with no currency symbol. See the cost-price trap below.
Inventory quantityOnly for single-location stores. Multi-location stores use Shopify's separate inventory CSV.
Weight value (grams)Grams only, no unit. Convert pounds and ounces first if you use calculated shipping rates.
BarcodesEAN/UPC codes. Watch for Excel stripping leading zeros. Multiple barcodes are separated with semicolons.
Image SrcA public image URL per image. Shopify downloads the image at import, so the supplier's links have to stay live until it finishes.

The cost-price trap

Most supplier files list cost - what you pay them. Shopify's Price column is what your customer pays. Importing a cost column as the selling price is one of the most expensive mapping mistakes there is: products go live at cost. Decide your margin first, put the computed retail price in Price, and keep the supplier cost out of the import file entirely (or in a metafield you set up deliberately).

Format rules that quietly break imports

- Save as UTF-8 CSV. Excel's default export settings can mangle characters and delimiter settings vary by region.

- Prices are numbers with a point, never a currency symbol, and a decimal comma (19,99) is a structural problem in a comma-separated file - it needs a human decision, not a find-and-replace.

- Values containing commas (tag lists, descriptions) need quoting; spreadsheet apps do this for you, plain text editors do not.

- TRUE/FALSE columns (Published on online store, Variant Requires Shipping, Variant Taxable) expect true or false, not yes or 1.

More detail on the errors that do the most damage - including how a missing option column can delete existing variants when you overwrite products - is in our companion guide: Shopify CSV import errors that delete variants (and how to catch them first).

Test with one product before the whole file

Map one product, import it, and look at it in the admin: variants, price, stock, images. Only then run the full file. If you are updating existing products, read Shopify's warning on Overwrite products with matching handles first - blank columns overwrite existing values with blank.
