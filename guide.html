Shopify CSV import errors that delete variants (and how to catch them first)

If you move supplier spreadsheets into Shopify, the dangerous mistakes are the quiet ones. The import finishes, nothing looks obviously wrong, and a week later you notice a product lost half its variants or a price is 100x too high. These are the errors worth checking before every import.

1. Missing option columns can delete variants

Shopify groups variants by Handle and defines them with the Option Name / Option Value columns. Shopify's own documentation warns that importing rows for an existing product without its option columns can delete the product's variants. This is the single most destructive common mistake: the supplier file has one row per SKU and no option columns at all, the importer treats it as a full replacement, and your Size/Colour variants are gone.

Check: for every existing product in the file, confirm the option columns are present and every variant you sell still has a row.

2. Duplicate SKUs

Two products sharing a SKU breaks stock tracking and makes some import tools overwrite one product with the other. Suppliers reuse SKUs surprisingly often, especially across seasons.

Check: every SKU in the file should map to exactly one product.

3. Decimal-comma prices ("19,99")

European suppliers often write prices with a decimal comma. If your pipeline reads "19,99" as text and strips the comma, the product goes live at 1999.00. It doesn't look like an error - it looks like a very expensive cap.

Check: any price containing a comma needs a human decision before import, not an automatic conversion.

4. Prices that aren't numbers

"NZD 19.99", "POA", currency symbols in the wrong place, or a formula that broke when the supplier exported. Shopify expects a plain number like 19.99.

5. Unintended price and stock changes

If you import over an existing store, the file can quietly change prices and quantities you didn't mean to touch - a supplier raised a cost, and your retail price silently follows. Compare the file against a current Shopify export first, and review every change before it goes live.

6. Barcode and boolean formatting

Excel loves stripping leading zeros from EANs, and TRUE/FALSE columns arrive as "yes", "1", or "Y". Each one is small; together they make an import fail in ways that take an afternoon to untangle.
