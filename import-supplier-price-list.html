How to import a supplier price list into Shopify without breaking your store

A supplier sends a spreadsheet. You need it in Shopify. Between those two points are a handful of decisions that decide whether the import quietly works or quietly wrecks existing products. This is the order to do it in.

1. Export your current products first

Before anything touches the store, export your product list from Shopify (Products → Export). This file does two jobs: it is your backup if the import goes wrong, and it is the comparison baseline that tells you what the supplier file would change.

Rule: no import without a fresh export sitting next to it.

2. Map the supplier columns to Shopify's format

Shopify's product CSV expects its own columns: Handle, Title, Option1 Name/Value, Variant SKU, Variant Price, Variant Inventory Qty and so on. Supplier files almost never arrive in that shape - they use their own names (RRP, Item Code, Stock), one row per SKU, and no option columns at all. Decide which supplier column feeds which Shopify column before you retype anything; the column-mapping reference covers the common supplier layouts.

Rule: map columns deliberately - never paste supplier columns over a Shopify export and hope the headers line up.

3. Check the file before it goes anywhere near the store

This is the step that catches the damage while it is still free to fix. The dangerous problems are quiet: a supplier file with no option columns can wipe an existing product's variants on import (Shopify documents this behaviour - a variant-related column without the option columns leads to existing variants being deleted), prices written with a decimal comma, duplicate SKUs, barcodes that lost their leading zeros in Excel. The six errors worth checking guide lists them with examples.

Rule: every problem found now costs a minute. The same problem found after import costs an afternoon.

4. Import carefully - and understand the overwrite switch

Shopify's import offers "Overwrite existing products that have the same handle". With it on, Shopify replaces values in the matching columns of existing products - and a blank non-required column in your file overwrites the existing value with blank. Import a small slice first (one product, or a handful of rows) and look at the result in the admin before running the whole file.

Rule: test with a few rows, check them in the admin, then run the rest.

5. Verify after import

Spot-check the products that already existed: variant counts, prices, stock quantities, images. Compare against the export from step 1. If something is wrong, that export is your way back.
